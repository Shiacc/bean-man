# 小动物美术规范（Style Lock）

> 20 只动物必须像同一个画师画的。这份规范是「锁」，做新动物前先读，做完用下面的检查项自检。
> 当前色板与 App 的 `Theme.Palette` 完全一致，别在素材里引入新颜色。

## 1. 画风定义

**扁平贴纸（flat sticker）**：纯色块 + 均匀深棕描边 + 圆润几何，没有任何渐变、纹理、投影、内发光。
参考气质：儿童绘本贴纸、LINE 表情包、Duolingo 角色的「简」而不是「精」。

| 维度 | 规则 |
|---|---|
| 比例 | 头大身小，头宽 ≈ 身体宽 × 1.6；眼睛占总脸高 45% 左右 |
| 视角 | 正面偏 3/4（头微侧 15°），始终看向用户 |
| 描边 | 统一 `#3A2A22`，1024 画布下 11 px（缩放后视觉一致） |
| 转角 | 全部圆角；线端 `round`，线接 `round` |
| 投影 | **不要**。需要落地感时另出一层 8% 透明椭圆，单独资源 |
| 表情 | 只靠眼睛 + 嘴，不加眉毛、不加腮红以外的高光 |
| 手/爪 | 简化成椭圆，不画指头细节（最多三条短线） |

## 2. 色板（与 Theme.Palette 同源）

| 用途 | 值 |
|---|---|
| 品牌主色（角色主色基底） | `#E4703A` |
| 主色暗部 / 条纹 | `#C2571F` |
| 奶油色（肚皮、嘴部、爪尖） | `#FFF1E8` |
| 描边 | `#3A2A22` |
| 腮红 | `#F3A183` 60% |
| 内耳 | `#F6C6B0` |
| 背景（导出时） | 透明 |

其他动物用自己的主色替换 `#E4703A` 与 `#C2571F`，奶油/描边/腮红**不变** —— 这是「同一个世界」的关键。

## 3. 尺寸与留白

- 画布 1024×1024，角色占宽 **70%–78%**，四周留 >= 10% 空白
- 脚底落在画布 91% 高度处（20 只对齐同一条地平线）
- 导出由 `Scripts/animal_pipeline.py` 统一裁剪 + 补方，视觉大小自动一致

## 4. 动画时值（App 内统一）

| 动作 | 时长 | 曲线 |
|---|---|---|
| 眨眼 | 120 ms 闭 + 立即开 | linear |
| 呼吸（缩放 1.00→1.03） | 2 400 ms 一轮 | easeInOut |
| 开心跳 | 380 ms | spring(damping 0.55) |
| 挥手 | 900 ms 一循环，最多 2 次 | easeInOut |
| 出场 | 260 ms，上移 8 pt + 淡入 | easeOut |

**规则**：同一屏只允许一个元素在动；用户正在答题时禁止任何装饰动画。

> **注意**：模型生成的是「草稿」，进 App 前必须过一遍下面的自检；能用矢量重画就重画（橘子就是矢量版）。

## 6. 交付自检（每只动物 8 条）

1. 缩到 48×48 还能认出物种吗？
2. 描边粗细与橘子一致吗？（把两张图并排放）
3. 只用了色板里的颜色吗？（取色器抽查 5 个点）
4. 透明底边缘有白边/灰边吗？（放到深色底上看）
5. 脚底是否在同一条地平线？
6. 眼睛高光方向是否一致（都在左上）？
7. 导出后有 @1x/@2x/@3x 三个尺寸且非简单放大（用 LANCZOS 重采样）？
8. `Contents.json` 的 `template-rendering-intent` 是 `original` 吗？（不然会被染色）

## 7. 已知坑

- **透明底**：Chrome 无头截图必须带 `--default-background-color=00000000`，否则是白底，后期抠图会留下白边。
- **描边被裁**：SVG 的 `stroke` 有一半在路径外，画布边缘要留够 11 px。
- **GIF 边缘锯齿**：GIF 只有 1 位透明，边会毛。预览用 APNG（PNG 序列），App 内用帧序列，别用 GIF。
- **别在 imageset 里放 README**：Xcode 会报 unassigned children 警告。
