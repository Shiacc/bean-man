# 小动物总谱 · 小豆的朋友们

> 20 只小动物，一人一个「场景角色」。它们不是装饰，而是替小豆分担特定情绪场合的**演员**：
> 小豆负责说话（文案），动物负责表情（视觉）。
> 命名规则：中文名给用户看，英文名给代码和文件名用。

## 设计前提

| 项 | 约定 |
|---|---|
| 角色定位 | 学习伙伴 / 情绪反馈，不承担教学功能 |
| 出场原则 | 一屏最多 1 只；同一时刻只有 1 只在动 |
| 视觉体量 | 96 / 128 / 256 pt 三档，缩到 48 pt 仍可辨认（剪影要能区分） |
| 与小豆的关系 | 小豆是「主持人」，动物是「来宾」：小豆说台词，动物给反应 |
| 出场方式 | 优先出现在卡片角落与小空状态，不打断学习流程 |

## 剪影差异化检查（缩到 48 pt 也要能认出）

- 耳朵形状：猫（三角）／兔（长垂）／柴犬（立耳）／柯基（大立耳）／仓鼠（小圆）／熊猫（黑圆）
- 头部配件：刺猬（尖刺）／羊（卷毛边）／螃蟹（钳子）／萤火虫（发光尾）
- 体型：熊（壮）／树懒（长臂）／海豹（无腿）／小鸟（小）
- 已刻意避开：两只同样的圆头四足动物占据相邻场景
