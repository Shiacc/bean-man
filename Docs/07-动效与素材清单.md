## 二、素材矩阵（要出多少张图）

> 现状（2026-11 核对 `Assets.xcassets/Animals`）：主立绘 **20/20**、`happy` **8/20**、`blink` **5/20**、`sleepy` **8/20**、`surprised` **0**。缺图时 `AnimalView` 自动回落主立绘，所以「缺表情」只是表现力少一层，不会破版。

| 表情 | 语义 | 用在哪 | 覆盖 | 还缺 |
|---|---|---|---|---|
| `normal` | 常态 | 今日页气泡、列表头像 | **20/20** | — |
| `happy` | 开心 / 完成 / 答对 | 完成页、成就、付费成功 | 8/20（布丁 / 团子 / 咕噜 / 橘子 / 棉花 / 泡泡 / 雪球 / 芝麻） | 12 只 |
| `blink` | 眨眼（120 ms） | 呼吸循环随机触发 | 5/20（布丁 / 橘子 / 棉花 / 雪球 / 芝麻） | 15 只 |
| `sleepy` | 犯困 | 五个空状态 | 8/20（同上 happy 那 8 只） | 12 只 |
| `surprised` | 惊讶 | 拼写错误、答错 | 0/6 | 6 只（橘子 / 布丁 / 泡泡 / 雪球 / 团子 / 小柚） |

**还缺表情的 12 只**：阿呜、刺刺、豆芽、呱呱、啾啾、卷卷、咔咔、慢慢、闪闪、小柚、云朵、竹竹。
合计 **39 张**（12 happy + 15 blink + 12 sleepy）+ 6 张 surprised，按 ¥0.24/张 ≈ **¥11**。

不想出全也没关系：`AnimalView` 的回落链是「指定表情 → 主立绘 → 占位图」，缺哪只都不影响功能。

## 三、刻意不做的

| 不做 | 为什么 |
|---|---|
| idle 8–12 帧 APNG | 呼吸用 `scaleEffect` 就够了，帧序列只在设计稿/宣传里用（已有的 `juzi-idle.apng` 保留作演示） |
| 跳跃 / 挥手帧序列 | 挤压（squish）+ 位移用代码做更顺滑，改参数不用重出图 |
| 特效贴纸（星星/音符/汗滴/问号） | 现在 SF Symbols 够用；等品牌化需要再补，4 个 PNG 随时可加 |

## 四、出表情的流水线（复用 v2）

1. **以主立绘为参考图**做 `edit_image`，只改眼睛/嘴 —— 比重新生成更能保住同一只角色；
2. 提示词固定：`Use the exact same <animal> character from the reference: identical colors, outline weight, proportions, cheeks and white background. Change ONLY the eyes: ...`;
3. 新图走 `Scripts/ai_cutout.py` 抠白底 → `<Name>Happy.imageset`（**单档 512 通用图**，`--sizes 512`）；
4. `Scripts/ai_expression_sheet.py` 拼对照图验收；
5. 回归：`AnimalExpression` 的 `assetName(for:)` 拼 `<Name>Happy` / `<Name>Blink` / `<Name>Sleepy` / `<Name>Surprised`，缺图自动回落到主立绘。

## 五、代码里已经接好的点

- `AnimalView(animal:size:expression:animated:breathe:)`：`animated` 管眨眼，`breathe` 管呼吸，`Reduce Motion` 时全部静止；
- `TodayViewModel.xiaodouExpression`：有任务 `.normal`、有学习记录 `.happy`、无任务 `.sleepy`；
- `StudySummaryView`：`.buding` + `.happy` + `ConfettiBurst`；
- 空状态：错词本 / 生词本（雪球 `.sleepy`）、词库（咕噜 `.sleepy`）、测试 / 弹幕（泡泡 `.sleepy`）。

也就是说：**图出好之后，把 imageset 放进 `Assets.xcassets/Animals/` 就会自动生效**，不需要改代码。
