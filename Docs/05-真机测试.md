# 真机测试：三条路，按「有没有 Mac / 有没有 $99 账号」选

| 路线 | 需要什么 | 有效期 | 能测到什么 | 成本 |
|---|---|---|---|---|
| **A. 未签名 IPA + Sideloadly 自签** | Windows + 数据线 + 免费 Apple ID | **7 天**（到期重签） | 全部功能，单台设备 | 0 |
| **B. TestFlight 内测** | Apple Developer $99/年 | 每次构建 90 天 | 全部功能 + 可发多人 | ¥688/年 |
| **C. Xcode 直接跑** | 一台 Mac | 7 天（免费账号）/ 1 年（付费） | 全部功能 + 能调试 | 借电脑 |

三条路都要求 **iPhone 系统 ≥ iOS 17.0**（工程的 deployment target 是 17.0）。

---

## 路线 A：今天就能装到手机上（推荐先走这条）

### A1. 让 CI 打一个未签名 IPA

1. 仓库 → **Actions** → 左侧 **未签名 IPA（给真机自签用）** → **Run workflow**
   - ⚠️ 这个 workflow 是**手动触发**的，日常 push 不会跑，不烧 macOS 分钟
2. 等 6–10 分钟，页面底部 **Artifacts** 下载 `BeanMan-unsigned-ipa`
3. 解压得到 `BeanMan-unsigned-Release.ipa`

> 为什么是「未签名」：签名必须用你的 Apple ID 在**你的电脑**上做。
> CI 只负责把机器码编出来，不碰你的账号。

### A2. Windows 上签名并安装（Sideloadly）

1. 装 [Sideloadly](https://sideloadly.io/)（免费）；如果 iPhone 连不上，再装
   [Apple Devices](https://apps.microsoft.com/detail/9np83lwlpz9k)（微软商店，替代 iTunes 驱动）
2. iPhone 用数据线连电脑 → 手机上点「信任此电脑」
3. 打开 Sideloadly：
   - **IPA**：选刚解压的 `BeanMan-unsigned-Release.ipa`
   - **Apple ID**：填你的 Apple ID（免费账号即可，不需要开发者账号）
   - **密码**：填 Apple ID 密码。开了双重认证的，去
     [appleid.apple.com](https://appleid.apple.com) → 登录与安全 → **App 专用密码** → 生成一个填这里
4. 点 **Start**。第一次会问你「是否注册设备 UDID」，选 **是**（免费账号靠这个把设备绑到证书上）
5. 手机上：**设置 → 通用 → VPN 与设备管理 → 开发者 App → 信任你的 Apple ID**
6. 回桌面，点开「豆卡单词」

### A3. 免费签名的限制（都能接受）

- **7 天过期**：到期后 App 打不开，重跑一次 Sideloadly 即可（不用重新下载 IPA）
- 一个 Apple ID 同时最多签 **3 个** App
- 没有 Push 通知、iCloud、HealthKit 之类需要付费账号的权限
  —— 我们只用本地通知（`UNUserNotificationCenter`）+ 系统 TTS，**免费签名完全够用**

### A4. 装上去之后重点测这几件

| # | 测什么 | 怎么判断过了 |
|---|---|---|
| 1 | 数据真的落盘 | 学 5 张卡 → 上滑杀进程 → 重开，进度还在 |
| 2 | 翻面动画 | 点击卡片有 3D 翻转，不是生硬切换 |
| 3 | 四档评分 | 点「不认识」→ 该词进错词本；点「认识」→ 不进 |
| 4 | 错词本 | 今日页 → 错词本 → 三段筛选/搜索/左滑移出/点开详情 |
| 5 | 发音 | 点喇叭读出单词，切英音/美音音色不同（真机音色和模拟器不一样） |
| 6 | 引导 | 首次进今日页弹出「这里开始」的挖洞提示，点「知道了」后不再出现 |
| 7 | 深色模式 | 控制中心切深色，界面跟随、文字不糊 |
| 8 | 动态字体 | 设置 → 显示与亮度 → 文字大小调到最大，不截断 |
| 9 | VoiceOver | 打开旁白，卡片能被读出「abandon，动词，放弃」 |
| 10 | 崩溃 | 连点 20 张卡不崩；崩溃日志可在 设置 → 隐私 → 分析与改进 → 分析数据 里找到 `BeanMan-*.ips` |

## 路线 B：TestFlight（有开发者账号后）

1. 4 个 Secrets 配好（见 [04-上架操作清单](04-上架操作清单.md)）
2. Actions → **Release to TestFlight** → Run workflow
3. 上传成功后：App Store Connect → **TestFlight** → 内部测试 → 把自己加成测试员
4. iPhone 装 **TestFlight** App → 接受邀请 → 安装「豆卡单词」

相比路线 A 的好处：不用连线、不用 7 天重签、能给朋友装、崩溃报告自动收集。

## 路线 C：有 Mac 时最快

```bash
brew install xcodegen
cd beanman-ios && xcodegen generate
open BeanMan.xcodeproj     # 选中你的 iPhone → ⌘R
```

免费 Apple ID 也能跑（Xcode → Signing & Capabilities → Team 选 Personal Team），
同样 7 天过期；付费账号则 1 年。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| Sideloadly 报 `Unable to connect to device` | 缺 Apple 驱动 | 装 Apple Devices（微软商店）后重插 |
| 报 `The maximum number of apps for free development profiles has been reached` | 免费 ID 同时签了 3 个 App | 删掉手机上别的自签 App |
| 报 `Your device is not registered` | 第一次没勾注册 UDID | 重跑，弹窗选「是」 |
| 装好点开闪退 | 构建架构不对 / 证书没信任 | 先信任开发者；仍是闪退就在 Sideloadly 勾 `Enable debugging` 重装 |
| 7 天后图标变灰 | 免费证书过期 | 重跑 Sideloadly（IPA 不用换） |
