# 上架前准备（豆卡单词 · BeanMan）

> 这份文件记录「从零开始把 App 送上 TestFlight / App Store」的操作顺序，
> 每完成一步就把 `[ ]` 改成 `[x]`。

## 0. 现在就能做、不需要任何账号的

- [x] 工程能被 CI 编译（GitHub Actions `ios-build.yml`）
- [x] 单元测试能跑（`BeanManTests`）
- [x] 模拟器里能跑起来并截图（`screenshots` job 的 artifact）
- [x] 应用图标（1024，单尺寸，已去 alpha）+ AccentColor

## 1. Apple Developer Program（$99/年，一次性门槛）

1. 准备一个**没注册过开发者账号**的邮箱（建议独立于个人邮箱，后面会公开在 App Store 上）
2. 打开 https://developer.apple.com/programs/enroll/ → 用 Apple ID 登录 → Enroll
3. 选类型：
   - **Individual（个人）**：最快，只要身份证实名 + 人脸/电话确认，1–3 天
   - **Organization（公司）**：需要 D-U-N-S 编号（免费申请，邓白氏审核约 1–2 周）
4. 付款 $99（约 ¥688），中国区支持支付宝/银联
5. 审核通过后，Apple 会发确认邮件；此时才能：
   - 在 Certificates, Identifiers & Profiles 建 **App ID**（Bundle ID `com.yourname.beanman`）
   - 在 App Store Connect 建 App 记录
   - 生成 **App Store Connect API Key**

> ⚠️ 中国大陆上架额外要求：2023 年起，在中国区 App Store 上架的 App 必须有
> **工信部 App 备案号**（通过云服务商/接入商提交，个人也能办，通常 1–2 周）。
> 没有备案可以先用 TestFlight 内测，但**不能在中国区正式上架**。

## 2. 账号下来后要给我的 4 个值

App Store Connect → Users and Access → Integrations → **App Store Connect API** → 生成密钥（角色选 App Manager）：

| 名字 | 从哪来 | 放哪 |
|---|---|---|
| `ASC_KEY_ID` | 密钥列表里的 Key ID（10 位） | GitHub Secrets |
| `ASC_ISSUER_ID` | 页面上方的 Issuer ID（UUID） | GitHub Secrets |
| `ASC_KEY_P8` | 下载的 `AuthKey_XXXX.p8` **全文**（只能下载一次） | GitHub Secrets |
| `APPLE_TEAM_ID` | Membership 页面右上角 Team ID（10 位） | GitHub Secrets |

然后在仓库 Settings → Secrets and variables → Actions 里建这 4 个。

## 3. 我拿到之后怎么跑

```bash
# 手动触发（GitHub 网页 Actions → Release to TestFlight → Run workflow）
# 或命令行：
gh workflow run release-testflight.yml
```

流程：`xcodegen generate` → `xcodebuild archive`（自动签名）→ `-exportArchive` → `altool --upload-app`。
成功后：App Store Connect → TestFlight 里出现构建版本 → 加内测人员（100 人免审核）。

## 5. 常见卡点

| 报错 | 原因 | 处理 |
|---|---|---|
| `No profiles for 'com.yourname.beanman'` | 没建 App ID 或 Team ID 不对 | 先在开发者后台建 App ID |
| `ITMS-90725` | SDK 版本太旧 | 用 `macos-15` + 最新 Xcode |
| `Invalid Bundle ... missing icon` | 图标缺 1024 或带 alpha | 已修（`AppIcon-1024.png` 是 RGB） |
| `altool: The provided API key is invalid` | Secrets 里 `.p8` 多了换行/空格 | 整段粘贴，别删首尾 |
